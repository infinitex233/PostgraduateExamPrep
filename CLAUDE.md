# CLAUDE.md

This is the concise Claude Code entry point for this repository.
`AGENTS.md` is the authoritative repository policy and overrides this file.

## Read First

Before changing files, read `AGENTS.md` and the root `README.md`, then the
guide for the target area:

- `StudyProgress/README.md` for daily logs, reviews, indexes, and the dashboard.
- `StudyMaterials/README.md` for the materials map, followed by its
  `Library/`, `BookNotes/`, or `MistakeBook/` guide as appropriate.

Inspect the target records or source material before editing. Preserve
unrelated worktree changes and user-authored content as directed by
`AGENTS.md`.

## Commands And References

The root README lists the common dashboard, cache-query, and OCR commands.
Run them with the verified Python 3 interpreter selected by `AGENTS.md`;
Windows uses system Python without a repository virtual environment.

The area guides own their data formats, source-verification rules, build
checks, and task-specific handoff steps. Dated OCR cache coverage is recorded
in `StudyMaterials/Library/Cache/STATUS.md`.
