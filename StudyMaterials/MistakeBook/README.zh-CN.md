## 记录格式

每份错题本顶部保留 Typora 的 `[TOC]` 标记，其后使用科目全称作为一级标题。标题只用于组织章、节和知识点，单道错题作为普通正文记录，不为错题单独建立标题。

每道错题使用以下结构：

```markdown
**题目 1**

题目内容。

**答案**

最终答案。

**解析**

解题过程、关键步骤和必要说明。

> 来源：《教材完整名称》，对应章节，第 xx 题，书内第 xx 页 / PDF 第 xx 页。
```

需要编号时，在当前小节内对错题局部编号。来源放在每道错题的最后一段，并统一使用以 `> 来源：` 开头的 Markdown 引用块。

## 维护规则

- 将错题加入对应的章、节或知识点下，只为已有错题建立必要的章节层级。
- 每道错题只记录题目、答案、解析和来源，不添加 YAML 元数据、复习计划、掌握状态或每日学习记录链接。
- 更新文件时保留已有错题、个人标注、排序和表述，在用户内容周围追加或合并，不整份覆盖。
- 保持题目条件和选项的原始顺序，准确记录公式、符号、表格和图示；确实需要本地辅助图片时使用相对链接。
- 答案保持简洁，推导过程、方法说明和注意事项写入解析。
- 遵守仓库现有的 Typora 数学格式。行间公式的 `$$` 分隔符必须单独占行，不能放入标题或引用块。
- 沿用 `BookNotes` 的空行风格：最小层级标题已有正文时，在下一个标题前保留三个空白行；文件最后一行之后不追加空白段落。

## 来源核验

- 先使用 `scripts/query.py` 搜索本地 OCR 缓存；涉及准确原文、公式、图示、题号或书内页码时，再打开源 PDF 核验。
- 使用教材完整名称，并在能够确认时记录对应章节和题号。
- 区分“书内印刷页码”和“PDF 页码”。PDF 页码指阅读器或缓存中的实际页面序号。
- 来源信息无法确认时写明“未确认”，不自行推测。
- 维护错题本时不重命名、移动、修改或复制本地源 PDF。
