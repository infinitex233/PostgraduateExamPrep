# 教材笔记

[English](README.md) | 简体中文

本目录按学科类别保存滚动更新的教材笔记：

- `Math/`：数学一教材笔记。
- `408/`：408 计算机专业课教材笔记。

每本教材维护一份笔记并逐章更新。保留用户的个人标注和既有排序，同时保持源教材与派生笔记分离。

## 高数强化笔记

- 笔记文件：[高数强化笔记.md](Math/高数强化笔记.md)
- 对应教材：《27武忠祥高数辅导讲义-强化》。
- 源文件：[27武忠祥高数辅导讲义-强化.pdf](../Library/Math/Intensive/27武忠祥高数辅导讲义-强化.pdf)。
- 更新方式：按照教材顺序逐章更新，只整理已经学习并核对过的章节。
- 整理原则：不抄录例题原题；例题中可迁移的结论、方法和易错点提炼为知识点。
- 页码格式：“书内印刷页码 / PDF 页码”。PDF 页码指阅读器中的实际页面序号。
- 内容标记：“教材提炼”表示教材原有知识；“复习提示”表示为做题而重组的方法框架。

## 内容分层

- 更新章节前先阅读对应源文件页面，只把经过核验的内容合并到既有笔记中。
- 教材主体内容保留在普通正文中，包括定义、定理、独立公式、关键结论、方法树、操作步骤和检查清单。
- 推导思路、证明提示、详细解释、注意事项、记忆方法和错因分析等补充说明使用 Typora 引用块。每个解释段落都以 `>` 开头，引用段落之间使用一行仅含 `>` 的引用空行分隔。
- 补充说明引用块中的公式使用 `$...$` 行内数学格式。较长推导拆分到多个引用段落中，不得使用 `> $$` 展示公式分隔符。
- 编辑章节时，将附近明确属于补充说明的内容调整为上述引用格式，但不要仅为改变样式而重排无关的教材主体内容。
- 优先整理可复用的框架、定义、考试题型、易错点和切入方法，不大段复刻教材。

## 维护规则

- 长篇笔记在文件顶部保留 Typora 的 `[TOC]` 标记，不再维护一份重复的手写大纲。
- 每个最小标题段落已有正文时，按照参考笔记格式在下一个标题前保留三个空白行；文件最后一行之后不追加空白段落。
- 对定义、公式、定理、重要结论和易错点尽量保留页码。
- 只更新当前正在复习的章节。保留用户已有的增删、标注、排序和个人表述，在其周围合并内容，不整份覆盖笔记。
