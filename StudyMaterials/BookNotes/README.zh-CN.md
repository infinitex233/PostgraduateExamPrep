## 内容分层

- 更新章节前先阅读对应源文件页面，只把经过核验的内容合并到既有笔记中。
- 写入前先阅读当前笔记的已有章节，沿用以知识为主线的叙述方式、标题粒度和排版。用户最新要求优先于既有样式，不为追求一致而照搬旧问题。
- 笔记应能脱离原题独立阅读。正文用知识名称或方法名称起笔，也可以直接陈述定义和结论，不要求每段都有加粗引导词。
- 不在正文或章首添加“教材提炼”“复习提示”等编写过程标签或对应的标签说明。确有必要区分补充推导、原书纠错与教材原文时，在对应引用块中说明。
- 教材主体内容保留在普通正文中，包括定义、定理、独立公式、关键结论、方法树、操作步骤和检查清单。
- 推导思路、证明提示、详细解释、注意事项、记忆方法和错因分析等补充说明使用 Typora 引用块。每个解释段落都以 `>` 开头，引用段落之间使用一行仅含 `>` 的引用空行分隔。
- 补充说明引用块中的公式使用 `$...$` 行内数学格式。较长推导拆分到多个引用段落中，不得使用 `> $$` 展示公式分隔符。
- 编辑章节时，将附近明确属于补充说明的内容调整为上述引用格式，但不要仅为改变样式而重排无关的教材主体内容。
- 从例题和习题中提取独特的方法、适用条件、可复用结论和易错点，再融入对应知识主题。不得以“例题结论”“习题迁移”或题号组织正文，不保留孤立数值、选项字母及脱离题干的答案。
- 确实需要具体情境才能讲清的方法，在引用块中补齐最少条件，简要说明推理，使示例可以独立读懂。不复制完整题干，不展开答案清单。
- 章节按知识主题分节。跨章节联系、方法选择及自检提醒就近放到对应知识点中；重复内容合并为一份，不再另设汇总板块。
- 需要短引导词时，用知识名称或方法名称表达实际内容。只有独立知识主题才增加标题，不因区分例题、习题或提醒而增加目录层级。补充说明按上方规则使用引用块。

## 强调标记

- 加粗 `**…**` 用于定理、公式、方法与核心概念名称在正文出现处，以及条目或段落开头有实际含义的短引导词。中文笔记的全角冒号放在加粗范围之外，编号与引导词一起加粗。不为套用加粗格式而新增固定编写标签。
- 高亮 `==…==` 只用于引用块警示句中的易错短语。每个最小标题段落至多一处，短语应逐条斟酌取完整分句，不批量机械套用。
- 强调标记不得出现在 `$...$` 行内数学、`$$` 展示块、标题行或表格行中。每对标记不跨行；不在既有加粗内嵌套，避免相邻 `****`。
- 强调标记只是附加格式，不改变上文的内容分层规则：教材主体仍在正文，补充说明仍在引用块。

## 维护规则

- 长篇笔记在文件顶部保留 Typora 的 `[TOC]` 标记，不再维护一份重复的手写大纲。
- 每个最小标题段落已有正文时，按照参考笔记格式在下一个标题前保留三个空白行；文件最后一行之后不追加空白段落。
- 对定义、公式、定理、重要结论和易错点，尽量使用“书内印刷页码 / PDF 页码”引用。PDF 页码指阅读器中的实际页面序号。例题和习题号只作为出处，与双页码一起放到对应知识点末尾的出处引用块，不作为标题、加粗标签或正文条目名称。
- 按知识覆盖检查完整性：保留独特知识、方法、公式、适用条件和必要纠错及其来源。重复方法合并，具体题目的数值答案可删除；不得为了题号覆盖率保留冗余内容。合并分节时将标题重新连续编号。
- 只更新当前正在复习的章节。保留用户已有的增删、标注、排序和个人表述，在其周围合并内容，不整份覆盖笔记。
- 新写的章节内容从一开始就按上述约定加标记；未经明确要求，不整篇回改无关章节的样式。
- 完成前自查：数学段内不含 `**` 与 `==`，标记成对，且未引入 `***` 或 `****`。
- 逐节检查能否独立阅读：没有编写过程标签、题号驱动的答案清单或缺失的适用条件；题号只出现在出处引用块中，合并后没有丢失独特知识。

## 写法示例

正文不得写成“习题 9：得到某个数”或“教材提炼：定义……”：前者脱离题干且没有提炼可复用知识，后者用编写标签代替了直接的知识叙述。

以下仅演示直接陈述知识、必要说明和末尾出处的关系，不是每段必须套用的模板；实际写入时省去不必要的说明，并将出处占位内容替换为核验过的来源。
