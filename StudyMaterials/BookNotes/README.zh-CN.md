# 教材笔记

[English](README.md) | 简体中文

本目录按学科类别保存滚动更新的教材笔记：

- `Math/`：数学一教材笔记。
- `408/`：408 计算机专业课教材笔记。

每本教材维护一份笔记并逐章更新。保留用户的个人标注和既有排序，同时保持源教材与派生笔记分离。

## 高数强化笔记

- 笔记文件：[高数强化笔记.md](Math/高数强化笔记.md)
- 对应教材：《27武忠祥高数辅导讲义-强化》。
- 源文件：[27武忠祥高数辅导讲义-强化.pdf](../Library/Math/Intensive/27武忠祥高数辅导讲义-强化.pdf)。
- 更新方式：按照教材顺序逐章更新，只整理已经学习并核对过的章节。
- 整理原则：不抄录例题原题；例题中可迁移的结论、方法和易错点提炼为知识点。
- 页码格式：“书内印刷页码 / PDF 页码”。PDF 页码指阅读器中的实际页面序号。
- 内容标记：“教材提炼”表示教材原有知识；“复习提示”表示为做题而重组的方法框架。

## 维护规则

- 长篇笔记在文件顶部保留 Typora 的 `[TOC]` 标记，不再维护一份重复的手写大纲。
- 每个最小标题段落已有正文时，按照参考笔记格式在下一个标题前保留三个空白行；文件最后一行之后不追加空白段落。
- 对定义、公式、定理、重要结论和易错点尽量保留页码。
- 只更新当前正在复习的章节，并保留已有个人笔记。
